# Demo Script — 7 minutes

## 0:00 — Positioning
“This is not a news dashboard. It is a decision-intelligence layer.”

## 0:45 — Global picture
Open the map and select three different event types.

Explain that the demo data is synthetic and that production adapters will expose source and freshness metadata.

## 2:00 — Evidence viewer
Show how the selected event becomes contextual evidence instead of only a map marker.

## 3:00 — Agent swarm
Run a scenario through the six agents.

Explain that each role asks a different question and the synthesis layer is designed to expose disagreement.

## 4:30 — Operational workflow
Show the event log and explain human approval.

## 5:15 — Enterprise architecture
Point to source adapters, canonical events, correlation, agent orchestration and audit trail.

## 6:00 — Business
Explain the initial vertical wedge and paid pilot model.

## 6:40 — Close
Ask for a design partner, source access or pilot budget — not vague “feedback”.
